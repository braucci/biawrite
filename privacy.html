BiaWrite — informativa sulla privacy

BiaWrite è un'applicazione web per scrivere appunti, realizzata da B. Raucci per uso personale e pubblicata come software libero.

Quali dati tratta

BiaWrite non ha un server proprio e non raccoglie, non riceve e non conserva alcun dato degli utenti. Tutto avviene nel browser di chi la usa.

Chi la collega a GitHub fornisce una chiave d'accesso creata sul proprio account, che di norma apre un solo repository privato. Con quella chiave l'applicazione legge e scrive le note nella cartella note di quel repository, e nient'altro.

Dove restano i dati

Le note sono conservate nel repository privato dell'utente su GitHub e, in copia, nell'archivio locale del browser del dispositivo in uso, per poter lavorare senza rete. La chiave d'accesso resta nel dispositivo: cifrata, se l'utente imposta un PIN. Nessun dato è trasmesso a terzi diversi da GitHub, e a GitHub soltanto per leggere e scrivere quei file.

Lo stesso vale per il diario alimentare, per chi usa quel modulo: il file scelto resta nell'archivio locale del browser e, se GitHub è collegato, nel repository privato dell'utente (cartella diario/). Non viene inviato a nessun altro.

Come revocare l'accesso

Dalle impostazioni di BiaWrite si può scollegare il dispositivo, cancellando la copia locale e la chiave. La chiave si revoca in qualunque momento dalla pagina Fine-grained tokens del proprio account GitHub.
